
## 三种「文档」的区别

| 文件 | 谁生成 | 性质 |
|---|---|---|
| `数据速览.md` / `stats.json` | `stats.mjs` | 纯统计，**可复算**，数字可信 |
| `剧本逆推/EPxxx.md` | `structure.mjs` | 镜头 × 字幕对齐的**逐镜台词表**（台词来自听写，可能有错讹） |
| `拆解报告.md` / `剧情结构逆推.md` / `剧情库卡片.md` | `auto-report.mjs` 初稿 + `prompts/` 精修 | **分析判断**，含推断，需人工核对 |

写作时要区分「数据事实」和「推断」，分析类报告里对未确证的听写/术语标注「待核」。
